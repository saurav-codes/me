The story so far

I taught myself to code on freeCodeCamp, then spent five years shipping Django backends for clients around the world: payroll SaaS, recruiting tools, lead routing, voice AI. Remote gigs, full-time and freelance.

Between jobs I took breaks on purpose, and I used them to build my own projects. ox (deploy platform), LazyPlanner (AI planning SaaS), Tymr (focus timer), plus plenty of ideas that never left the notebook. Those breaks were also school of a different kind: Go, HTMX, real-time AI, what makes design good, and sales (cold email, copywriting, reading buyers).

Now I am trying to make my own indie products work, ox first. It deploys apps from GitHub to a server you own, and LazyPlanner already runs on it. I still keep a foot in client work when I want it.

Projects

ox

Beta, free Go · HTMX · systemd · Caddy

My main project. Connect a GitHub repo and ox deploys it to your own Ubuntu server with systemd and Caddy, no Docker. It reads the repo, so most stacks need no config.

  • Checks a plan before every deploy, switches releases with no downtime, and keeps the live one running if an update fails.
  • One-click rollback, daily backups, and preview environments per branch that you can promote.
  • A console, a CLI with --json on every command, and an llms.txt for AI agents.
  • Runs my own LazyPlanner and a live demo zoo of 24 apps on 4 servers, with 45 example repos on GitHub.
